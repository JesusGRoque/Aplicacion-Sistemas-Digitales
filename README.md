# Palabra de 4 bits en display de 7 segmentos de ánodo común
Se pide mostrar una palabra de 4 letras a través de un display de 7 segmentos de ánodo común, para ello usaremos el método de tabla de verdad, en el cual definiremos dos bits de entrada, y siete salidas que corresponden a cada uno de los segmentos del display.
